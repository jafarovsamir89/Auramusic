# AURA ChartBrain

В AURA теперь есть два типа контента:

1. Трендовые чарты (`top-today-world`, `top-week-world`, `new-this-week`, региональные) — обновляются генератором снимка.
2. Постоянные редакционные коллекции (`hits-90s`, `artist-50cent`, `artist-ruki-vverh`, `aura-calm-night`) — меняются только осознанным обновлением каталога.

## Как собирается рейтинг

`tools/playlists/chart_brain.py` читает небольшие снимки источников из
`tools/playlists/sources/`, нормализует названия и объединяет совпадающие
пары «исполнитель + трек». Для каждого источника учитывается позиция в чарте
(reciprocal-rank fusion), а не только абсолютное число прослушиваний. Поэтому
трек, который стабильно попадает в несколько чартов, поднимается выше
случайного вирусного результата одного сайта. Дубликаты и пустые строки
отбрасываются.

Источники подключаются только во время сборки: Official Charts публикует
недельный UK Singles Chart на основе streams, downloads и физических продаж;
Apple Music показывает ежедневные Top 100 по странам и миру; Spotify ведёт
daily/weekly/city charts; YouTube предоставляет `mostPopular` через Data API;
ListenBrainz даёт открытые агрегаты. Ссылки и ограничения использования
зафиксированы в `docs/chart-sources-audit-2026-08-13.md`.

## Почему не в рантайме

APK не парсит сайты и не хранит audio URL, cookies или извлечённый MP3. Если
один источник временно недоступен, остаётся последний валидный снимок, а
постоянные коллекции продолжают работать. При сборке результат записывается
атомарно в `app/src/main/assets/playlists/world_playlists.json`.

## Проверка

```bash
python3 tools/playlists/chart_brain.py
python3 -m py_compile tools/playlists/chart_brain.py
```

После запуска в APK попадают полноценные очереди треков: на главном экране
отображаются все непустые карточки, а нажатие на карточку последовательно
разрешает и добавляет песни в очередь через текущий музыкальный провайдер.
