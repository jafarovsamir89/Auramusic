# Стабильность каталога мировых плейлистов

Каталог мировых подборок не является критической зависимостью запуска AURA.

- Приложение читает локальный snapshot из `assets/playlists/world_playlists.json`.
- Внешние API не вызываются при старте приложения.
- Повреждённые записи отбрасываются, количество плейлистов и элементов ограничено.
- Песня из подборки разрешается через текущий provider resolver с отдельным таймаутом.
- Если одна песня недоступна, AURA пропускает её и продолжает подборку.
- Первый найденный трек запускается сразу; остальные добавляются в очередь после него.
- Генератор обновляет snapshot атомарно: временный файл заменяет основной только после полного успешного формирования.
- При ошибке сети существующий snapshot не перезаписывается.

Обновление выполняется вручную или в CI:

```bash
python3 tools/playlists/build_world_playlists.py --limit 50
```

Обогащение годами релиза обращается к MusicBrainz с ограничением скорости и использует локальный кэш:

```bash
python3 tools/playlists/build_world_playlists.py --limit 50 --all-time-limit 100 --enrich-years
```

Если источник недоступен, сборка APK всё равно использует последний проверенный snapshot.
